### hook
┌─────────────────────────────────────────────────────────────┐
│  你（在终端里）                                               │
│  输入："继续修这个bug"                                        │
│  然后 ↵ 敲回车                                                │
└──────────────────────┬────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────┐
│  Codex CLI 主程序（Rust 写的，负责终端交互）                   │
│  1. 捕获到回车键，知道你要发消息了                             │
│  2. 查配置：hooks.json 里有没有 "UserPromptSubmit" 事件？      │
│  3. 发现配了！命令是：node /path/to/hook.js                   │
└──────────────────────┬────────────────────────────────────────┘
                       │
                       ▼  执行脚本（子进程）
┌─────────────────────────────────────────────────────────────┐
│  Hook 脚本（那段 JS）                                         │
│  它被执行时，完全不知道自己为什么被调用                        │
│  它只是按部就班：                                              │
│    → 找项目根目录                                             │
│    → 读 .ccd/tasks/ 下的任务文件                              │
│    → 把任务状态打印到 stdout（标准输出）                       │
│    → process.exit(0)                                        │
└──────────────────────┬────────────────────────────────────────┘
                       │
                       ▼  Codex CLI 捕获 stdout
┌─────────────────────────────────────────────────────────────┐
│  Codex CLI 主程序                                             │
│  4. 读取 hook.js 打印的 JSON 字符串                            │
│  5. 解析出 additionalContext                                  │
│  6. 把这段上下文 + 你的原始消息，一起打包发给 Claude API       │
└──────────────────────┬────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────┐
│  Claude API 收到的最终请求                                     │
│  ------------------------------------------------------------ │
│  <ccd-state>                                                  │
│  Task: 修复登录bug (in-progress)                              │
│  Complexity: M2                                               │
│  Next: 检查 token 验证逻辑                                    │
│  </ccd-state>                                                │
│                                                               │
│  用户说：继续修这个bug                                         │
│  ------------------------------------------------------------ │
└─────────────────────────────────────────────────────────────┘
